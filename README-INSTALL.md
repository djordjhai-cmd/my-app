# 📱 Как получить APK файл - Простая инструкция

Привет! 👋 Вот самая простая инструкция, как получить готовый APK файл для Android.

У тебя есть **2 варианта**:

---

## 🚀 Вариант 1: Автоматическая сборка через GitHub (РЕКОМЕНДУЮ - проще всего!)

**Тебе НЕ нужно устанавливать Android Studio или Java!**

### Что нужно сделать:

#### Шаг 1: Создай аккаунт на GitHub
1. Открой сайт [github.com](https://github.com)
2. Нажми "Sign up" (Зарегистрироваться)
3. Придумай логин, email и пароль
4. Подтверди email

#### Шаг 2: Создай новый репозиторий
1. Нажми зелёную кнопку "New" или "+" → "New repository"
2. Назови проект (например, `my-app`)
3. НЕ ставь галочки (оставь всё как есть)
4. Нажми "Create repository"

#### Шаг 3: Загрузи файлы проекта
**Способ А - Через сайт (проще):**
1. Скачай весь проект как ZIP (у тебя должна быть кнопка "Скачать проект")
2. Распакуй ZIP в любую папку
3. На странице репозитория нажми "Add file" → "Upload files"
4. Перетащи ВСЕ файлы из распакованной папки (кроме папки `node_modules` и `android`)
5. Нажми "Commit changes"

**Способ Б - Через программу GitHub Desktop (ещё проще):**
1. Скачай [GitHub Desktop](https://desktop.github.com/)
2. Установи и войди в свой аккаунт
3. Нажми "Create new repository"
4. Выбери папку с проектом
5. Нажми "Publish repository"

#### Шаг 4: Получи APK
1. Подожди 2-3 минуты (внизу страницы появится жёлтый кружок, потом зелёная галочка ✅)
2. Перейди во вкладку **"Actions"** (вверху страницы)
3. Кликни на самый верхний запуск (там где зелёная галочка)
4. Прокрути вниз до раздела **"Artifacts"**
5. Нажми на `app-debug-apk` - скачается ZIP архив
6. Распакуй ZIP - внутри будет файл `app-debug.apk`
7. **Готово!** Перенеси этот файл на телефон и установи

---

## 💻 Вариант 2: Сборка на компьютере (сложнее)

Если хочешь собирать APK локально:

### Что установить:
1. **Node.js** - скачать с [nodejs.org](https://nodejs.org/) (выбери LTS версию)
2. **Android Studio** - скачать с [developer.android.com/studio](https://developer.android.com/studio)
3. **Java JDK 17** - обычно ставится вместе с Android Studio

### Что сделать:
1. Установи Node.js (просто нажимай "Далее" при установке)
2. Установи Android Studio (тоже "Далее" → "Далее")
3. Открой папку проекта
4. Запусти файл `setup-android.bat` (двойной клик)
5. Подожди, пока завершится
6. Открой папку `android` через Android Studio
7. Нажми **Build** → **Build APK**
8. Готовый APK будет в `android/app/build/outputs/apk/debug/`

---

## 📲 Как установить APK на телефон

1. Перенеси файл `app-debug.apk` на телефон (через USB, Telegram, email - как угодно)
2. Открой файл на телефоне
3. Если aparecerся предупреждение "Установка из неизвестных источников" - нажми "Настройки" и разреши
4. Нажми "Установить"
5. Готово! Приложение появится на рабочем столе

---

## ❓ Проблемы?

**Если что-то не получается** - просто выбери **Вариант 1** (GitHub). Там вообще ничего сложного нет!
