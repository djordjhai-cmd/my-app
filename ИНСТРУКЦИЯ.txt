🚀 СПОСОБ 1: АВТОМАТИЧЕСКАЯ СБОРКА (САМЫЙ ПРОСТОЙ!)
   ⏱️ Время: 10 минут
   💻 Ничего устанавливать НЕ нужно!

   Шаг 1: Зарегистрируйся на GitHub
   → Открой сайт: github.com
   → Нажми "Sign up" (зелёная кнопка справа вверху)
   → Придумай логин, email, пароль
   → Подтверди email (проверь почту)

   Шаг 2: Создай новый проект (репозиторий)
   → Нажми "+" → "New repository"
   → Название: my-app
   → Нажми "Create repository"

   Шаг 3: Загрузи файлы
   → Нажми "Add file" → "Upload files"
   → Выбери ВСЕ файлы из этой папки (кроме node_modules)
   → Перетащи их на страницу
   → Нажми "Commit changes"

   Шаг 4: Получи APK
   → Подожди 2-3 минуты
   → Перейди во вкладку "Actions" (вверху)
   → Кликни на зелёную галочку ✅
   → Прокрути вниз до "Artifacts"
   → Скачай "app-debug-apk"
   → Распакуй ZIP → внутри будет app-debug.apk
   → ГОТОВО! 📲 Установи на телефон

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💻 СПОСОБ 2: СБОРКА НА КОМПЬЮТЕРЕ (если хочешь сам)
   ⏱️ Время: 30 минут
   📦 Нужно установить: Node.js + Android Studio

   1. Установи Node.js: nodejs.org (скачай LTS версию)
   2. Установи Android Studio: developer.android.com/studio
   3. Запусти файл: setup-android.bat (двойной клик)
   4. Открой папку android в Android Studio
   5. Build → Build APK

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📲 КАК УСТАНОВИТЬ APK НА ТЕЛЕФОН:

   1. Перенеси app-debug.apk на телефон
      (через USB, Telegram, email - как удобно)
   2. Открой файл на телефоне
   3. Если спросит про "неизвестные источники" → разреши
   4. Нажми "Установить"
   5. Готово! 🎉 Приложение на рабочем столе
